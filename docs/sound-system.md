# 飞行声音系统

用户在声学实验室 v13 确认的参数保存在 `src/audio/calibration.json`，也是首次启动与“恢复已标定参数”的默认值：总音量 20%；电机 / 主齿 / 皮带 / 主桨 / 尾桨分别 130 / 40 / 130 / 90 / 100%；主桨爆桨响度 75%、亮度 56%；尾桨爆发响度 200%、融合音色、音高偏移 0 半音、余音 0.60 秒。持续尾桨动态 100%、右舵音高微调 1.5 半音。

实验室的 1940 RPM、38% 负载、68% 右舵和抽杆速度 100% 作为试听参考归档，不覆盖飞行器的实际转速、螺距或操纵量。

## 音源

- 五个持续旋转通道沿用实验室的振荡器谐波、带通噪声与过桨调制，由 Web Audio 实时合成。
- `public/audio/main-smack.wav` 来自用户提供的 `1791298205697023.MP4`，截取爆发和衰减、减弱持续背景并淡入淡出。不是纯程序合成。单声道 48 kHz / PCM16，0.7543125 秒。
- `public/audio/tail-switch-hybrid.wav` 是处理后的实录起音、旧版程序尾桨纹理和扩散余韵预先混成的单声道 48 kHz / PCM16，2 秒。飞行时按已保存的 0.60 秒包络收尾；音高和余音长度独立调整，最长受素材长度及播放速率限制。

两段素材总计约 265 KB，在用户首次交互后加载、解码一次并复用。没有后台 Worker、AudioWorklet 或实时卷积。每次爆发只分配一个采样音源；主桨、尾桨各最多保留 4 个瞬态，超出时淡出最早的一个。结束后断开并释放节点。

## 飞行状态驱动

`soundOperatingPoint` 读取实际主轴角速度、集体螺距、周期螺距和实际尾桨侧推力。持续声负载使用螺距幅值的平方根映射，正负螺距同样增加负载；幅值线性值用于动作检测，避免感知映射改变打杆加速度。实际 RPM 决定电机电频率、齿轮过齿频率和主尾桨过桨频率。关闭电机后继续跟随机械转速自然减速。

爆桨检测在现有 250 Hz 物理步进后运行，不读取键鼠事件次数。主桨跟随真实执行器的螺距变化速度和加速度，收集约 28 ms 的起音以确定强弱，保持杆量不重复触发。尾桨根据实际尾桨推力除以当前 RPM 下的推力上限，推导有符号桨距行程；扣除主桨反扭矩配平后影响持续声音色。

尾桨爆发单独根据机体实际偏航角加速度判断：先以 12 ms 时间常数平滑角加速度，超过 3500°/s² 后收集 40 ms 动作，要求期间偏航角速度有足够大的变化。响度由角加速度峰值和角速度变化共同决定，低于阈值静默；没有最小响度保底，也不再对小强度开平方放大。一次加速 / 制动波峰只触发一次，连续事件至少间隔 120 ms。轻微快打、缓慢大幅打舵、反扭矩前馈与尾舵微调不会单凭桨距变化触发；猛烈自旋停止和变向会触发，动作越猛烈声压越大。卸载方向为增载的 60%。当前音色映射为听感近似，不是测得的气动声压模型。

## 空间关系

同一个 AudioContext 中分为机身、主桨、尾桨三个空间组。电机、主齿与皮带共用机身位置；主桨持续声和主桨爆桨共用主轴声源、朝向增益及距离衰减；尾桨持续声和换向音共用独立尾端声源。

- 世界坐标以米计。主轴偏移 `(0, headHeight, 0)`，尾端 `(-tailArm, tailHeight, 0.0435)`，都通过当前机体四元数变换。尾端 Z 偏移与显示模型的尾轴位置一致。
- 主桨法线与物理桨盘一致，为归一化的 `(sin(discPitch), 1, sin(discRoll))`，再随机体姿态旋转。以它与“主轴到摄像机”方向点积绝对值的 1.5 次幂控制增益：桨盘任意一面完全正对时 1，完全侧对时 0.3（约 -10.5 dB）；“主桨朝向变化强度”可降低这项差异。
- 距离按压力幅值 `9 / distance` 衰减，近处封顶 1.5；9 米为标定参考，不是硬截止。远处逐渐减弱高频。Panner 的额外距离衰减设为 0，避免重复计算。
- 尾桨自旋远近变化由实际尾端世界位置产生，没有固定频率音量摆动。近处变化较明显，远处因尾臂长度相对距离变小而自然减弱。摄像机视野缩放不改变声源距离。
- Panner 采用 equal-power 立体声定位，监听器位置和朝向跟随实际摄像机；空间状态使用与画面相同的插值位置及姿态。

## 启停与设置

任意真实点击或按键解锁浏览器音频；没有额外阻断飞行的确认流程。菜单“声音设置”支持实时调总音量、五通道音量、主桨朝向强度及爆桨参数，按 `heli-lab.audio.v1` 保存在本机。音频不可用时不阻断飞行；素材失败时保留持续合成声，可点击“启用 / 重试声音”。

欢迎介绍、飞场设置暂停物理时同步淡出并清理瞬态；复位时清除动作历史，避免产生假爆桨。页面转入后台或关闭声音时淡出并暂停 AudioContext；返回后恢复已经解锁的音频。关闭电机本身不直接静音，遵循实际旋翼减速。

## 验证

`tests/audio.test.ts` 检查确认的参数、存储、实际状态映射、桨盘正反面 / 侧面、机体与桨盘姿态变换、尾桨一整圈的远近周期、距离衰减，以及保持 / 慢拉 / 连续快抽 / 尾舵换向。`tests/audio-harness.html` 可在浏览器检查真实 Web Audio 输出、电平、瞬态回收与空间模式；测试电平表不进入生产主页面。
